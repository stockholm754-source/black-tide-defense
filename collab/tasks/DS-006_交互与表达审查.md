发起：Codex，总工程师，2026-10-10。状态：待领取；先完成当前 DS-005，不打断现有跑局。本任务书用于共享文件协作，不代表 DeepSeek 已收到或开工。

## 目标

为“开局 → 首次选卡 → 首次交易 → 返回战斗”找出玩家无法发现入口、输入冲突、说明与机制不一致、退出后状态残留的真实问题。

## 范围

只读 `RogueUI.cs`、`ShopUI.cs`、`HUD.cs`、`HeroBase.cs`、`HeroWeapons.cs`、`RunDirector.cs` 和对应设计。核心代码由 Codex 修改，本任务只写 `collab/reports/DS-006_report.md` 与本任务状态。

重点检查：B / ZXC 与切武器的互斥，G / Esc 与战斗输入，倒地 / 切角色 / 离开商人 / 重开时的关闭，自动代打对 UI 的影响，商城文字 / 价格 / 库存 / 失败原因与实际行为，待选增益的可发现性，现有“自动升级”和用户提及“赐福点”的功能边界。

## 验收

- 每项给当前文件与位置、触发步骤、玩家后果、建议修法；已排除项写依据。
- 区分源码推断、静态可证、真实 Play 复现；不开新 Unity 实例，不与正在运行的测试争用编辑器。
- 优先最多 5 个影响真实体验的问题；不将纯个人喜好记为 bug，不新增玩法规则。
- 标注审查时源文件 SHA256 或可定位版本。完成后给 Codex 审阅；最终优先级与实机验收由总工负责。
