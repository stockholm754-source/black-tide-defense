| # | 用例 | 期望 | 失败判据 |

| P4 | 20 条词条接线 | `WeaponAffix.Def` 对 20 个 id 全部命中；`Describe`/`Weapons.Make`/`Kit.Rebuild` 正常 | 任一条 id 查不到 Def / 描述为空 |
